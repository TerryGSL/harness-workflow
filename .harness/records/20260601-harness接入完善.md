## Decisions（非显然取舍）
- **trailer 只加 Brainstormed-by,砍 Memory-Checked**(codex + 我一致):Memory-Checked 是"接手动作"不是 commit 产出,且和现有 Memory: 语义重叠(读取/写入),7 个 trailer 发胖。claude-mem 接手 query 改放 SKILL advisory 提示。
- **husky 只自动接 commit-msg+pre-commit,不接 pre-push**:pre-push 读 git stdin(refs),append 进 husky 脚本会破坏 stdin 透传。诚实标注 + CI 兜底,不假装完整。
- **lefthook/pre-commit-config 不自动改**:配置格式各异不通用,只提示。
- brainstorming/claude-mem 本质难机械验质量,trailer 是"可审计摩擦"非"质量保证"——和 Memory:/Reviewed-by 同类,接受可能被填 none,但逃逸显性化、可 grep。
- **codex 两轮审,6 项全修**:① husky 被 hooksPath 前置判断挡→提前判;② 提前后新引入"hooksPath 指别处仍 append"→收窄到仅空/.husky/.husky/_ 才自动接;③ Brainstormed-by 文档去 manual 统一;④ ci-gate feature 补 Plan 检查(镜像 verify-evidence,堵 --no-verify 绕过);⑤ 幂等用精确 marker;⑥ templates/WORKFLOW.md 同步 Brainstormed-by(目标 repo 读它,否则文档漂)。
